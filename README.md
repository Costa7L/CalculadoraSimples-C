# Calculadora em C

Projeto simples de uma calculadora desenvolvido na linguagem C para praticar conceitos básicos de programação.

## Funcionalidades

- Soma
- Subtração
- Divisão
- Multiplicação
- Verificação de divisão por zero
- Tratamento de opção inválida

## Tecnologias utilizadas

- Linguagem C
- Compilador GCC

## Conceitos praticados

- Variáveis
- Estruturas condicionais (`if`, `else if`, `else`)
- Operadores matemáticos
- Entrada e saída de dados (`scanf` e `printf`)
- Conversão de tipos (`float`)
- Organização de código

## Como executar

Compile o programa:

```bash
gcc main.c -o calculadora
```

Execute:

```bash
./calculadora
```

## Exemplo

```text
Digite o primeiro valor: 10
Digite o segundo valor: 2

===== CALCULADORA =====
[1] Soma
[2] Subtracao
[3] Divisao
[4] Multiplicacao

Escolha a operacao: 3

10 / 2 = 5.00
```
